# 🐍 Hora da Prática - Python para Data Science

Este repositório contém as resoluções dos desafios práticos propostos no material "Hora da Prática", referente ao curso de **Python para Data Science** da Escola de Dados da Alura.

O arquivo principal (`hora+da+pratica.py`) é um script que reúne diversos pequenos projetos e exercícios focados em consolidar a base da programação em Python, desde comandos básicos até a manipulação de estruturas de dados.

## 📚 Tópicos Abordados

O código está estruturado acompanhando as aulas do curso, abordando os seguintes conceitos:

* **Aula 1 - Introdução ao Python:**
* Uso da função `print()`.
* Formatação de strings (f-strings).
* Exibição de variáveis numéricas e de texto.


* **Aula 2 - Manipulando dados no Python:**
* Coleta de dados via terminal usando `input()`.
* Criação de calculadoras simples (soma, subtração, multiplicação, divisão, exponenciação e módulo).
* Edição e manipulação de textos (métodos `upper()`, `lower()`, `strip()`, `replace()`).


* **Aula 3 - Estruturas Condicionais:**
* Uso de `if`, `elif` e `else`.
* Lógica booleana e operadores de comparação.
* Projetos aplicados: cálculo de variação percentual, verificação de tipos de triângulos, e aplicação de descontos em combustíveis.


* **Aula 4 - Estruturas de Repetição:**
* Loops `while` e `for`.
* Uso da função `range()`.
* Projetos aplicados: cálculo de fatorial, identificação de números primos, geração de tabuadas e simulação de um sistema de votação.


* **Aula 5 - Estruturas de Dados:**
* Manipulação de Listas (`append()`, `reverse()`).
* Manipulação de Dicionários (chaves, valores e o método `items()`).
* Uso de funções built-in como `sum()` e `len()`.
* Projetos aplicados: análise de dados de vendas (e-commerce), cálculo de métricas biológicas de uma floresta, controle de bônus salariais e cruzamento de gabaritos com respostas de alunos.



## 🚀 Como executar

Como o arquivo é um compilado de diversos exercícios que utilizam a função `input()`, ao executá-lo, o terminal pedirá várias interações em sequência.

Para rodar o script localmente, certifique-se de ter o Python instalado na sua máquina. Abra o terminal e execute:

```bash
python hora+da+pratica.py

```

> **Dica:** Se você quiser testar apenas um exercício específico, recomendo comentar as partes do código que você não quer que rodem no momento, ou copiar o trecho desejado para um arquivo temporário.
